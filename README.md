## 👋 About Me

I'm a CSE undergraduate who enjoys turning practical problems into software while learning how computers and software systems work under the hood.

My long-term goal is to become a **deeply capable, cross-disciplinary engineer**: understanding computing from programming and algorithms through operating systems, computer architecture, networking, security, and software design, then using that knowledge to build meaningful technology products and eventually a company.

My path started with red teaming, then expanded into Web3 backend development, smart contract development, and audit practice. Alongside security, I've been building AI-powered tools, academic products, and other software. **Security is one part of the journey, not the whole identity.**
